# SWOT

---

# What It Is

A four-quadrant summary — strengths, weaknesses, opportunities, threats — splitting internal factors
from external ones.

The framework treats it as a **summarizing device with no output of its own.** It produces nothing
this module is required to deliver, and every quadrant duplicates work another module does more
rigorously:

| Quadrant | Where the framework does it properly |
| --- | --- |
| Strengths | `05-competition` — differentiation, evidenced against named rivals |
| Weaknesses | `10-Risks-and-Assumptions` deliverable, with likelihood and mitigation |
| Opportunities | Frame 5 — gaps, with the reason each persists |
| Threats | Frame 4 — the adversarial trend, with evidence |

It is documented here because it will be asked for, and because a run that reaches for it should
know what it is and is not entitled to conclude.

---

# When It Applies

Optionally, in the executive summary, after Frames 1–5 are complete. Never as analysis, and never
before — a SWOT written early becomes the analysis, and it is the weakest analysis in the framework.

---

# How to Apply It Here

**Populate it only from findings already tagged elsewhere.** Every cell must trace to a frame output
with its evidence tag intact. A SWOT with untagged content launders assumptions into conclusions in
the one artifact executives read most.

**Cap it, hard.** Two entries per quadrant. The value of a summary is what it leaves out.

**Keep internal and external honestly separated.** "Strong AI capability" is not a strength unless
someone comparable lacks it — that comparison is `05-competition`'s, and without it the quadrant is
self-description.

**Prefer the underlying artifacts when there is a choice.** A risk register with likelihood and
mitigation, and a differentiation table with evidence, do everything a SWOT does and can be acted
on.

---

# Where It Misleads

**It has no severity, no likelihood and no evidence requirement.** A fatal regulatory exclusion and a
minor inconvenience sit in the same box at the same size. This is the specific reason the framework
gives it no output: the format cannot distinguish a blocker from a nuisance.

**Strengths written before a product exists are aspirations.** "Fast to iterate", "domain expertise",
"modern stack" are claims about intent. `05-competition` requires differentiation to be evidenced;
this quadrant requires nothing, and gets filled accordingly.

**It invites symmetry.** Four boxes ask to be filled equally, so weaknesses get softened and threats
get thinned until the picture balances. Real market findings are lopsided.

**It ends analysis rather than directing it.** A completed SWOT feels conclusive while containing no
decision, no owner and no next action — the reason it survives in documents that change nothing.
