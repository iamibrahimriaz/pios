# Learn — Competition

---

# What This Layer Is

The human curriculum for the Competition module. An executing agent does not read it.

---

# What the Module Does

It maps who already solves this, how well, and where the opening is. It produces a
competitor matrix, feature and pricing comparisons, a gap analysis, and positioning.

Its gate contains one requirement that surprises people: **"do nothing / status quo"
must be evaluated as a competitor.** That is not a rhetorical flourish. In most markets
it is the largest competitor by share, and it is the one nobody profiles.

---

# The Three Things Worth Learning Here

**The status quo is undefeated in most markets.** It costs nothing, requires no
learning, has never lost anyone's data, and fits the user's process exactly — because
it *is* their process. Module 03 documented it; this module has to score it fairly.

**A gap is not an opening until you know why it is empty.** Three reasons exist: nobody
has got to it, nobody can, and nobody should. Only the first is an opportunity, and it
is the rarest. The gate asks for a defensible gap *with reasoning* for exactly this
reason.

**Positioning is a claim about a specific alternative.** "Better and easier" is not
positioning; it is a mood. Positioning names who you beat, for whom, and at what.

> A competitor analysis that concludes you are better than everyone at everything has
> not analyzed anything. It has described an ambition in a table.

> **Learn Principle**
>
> The purpose of this module is not to establish that you can win.

> defensible for longer than a quarter.
