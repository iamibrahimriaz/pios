# Hypothesis

---

# What It Is

A statement that could be shown to be wrong.

An idea becomes a hypothesis when it acquires that property. Before then it is a description,
and descriptions cannot be researched — only elaborated.

The usable form:

> We believe **«who»** will **«do what»** because **«why»**, and we will know we are wrong if
> **«observable result»**.

The last clause is the whole point. A statement with no result that would refute it is not a
hypothesis, however carefully it is written.

---

# When It Applies

In Pass 5 (Interrogate), after the problem and solution have been separated and the context
located.

It is also the form every later assumption takes. Module 06's load-bearing assumption, module
07's bet, module 11's growth assumptions and module 14's quality expectations are all
hypotheses, and they are all expected to carry a refutation condition.

---

# How to Apply It Here

**Write the refutation clause first.** Ask what result would make you abandon the idea, then
write the belief that result would refute. Working the other way produces beliefs with
decorative test conditions attached.

**Distinguish the three hypotheses inside most ideas:**

| Type | Claim | Tested by |
| --- | --- | --- |
| Problem | This difficulty is real and costly | `04-problem` |
| Solution | This approach relieves it | `07-strategy`, then a build |
| Business | Someone will pay enough | `06-business` |

Conflating them produces one large statement that cannot be tested at all. Separated, each has
a different cheapest test, and the problem hypothesis is almost always the cheapest.

**Make the observable specific.** "Users are not interested" is not observable. "Fewer than two
of ten GPs asked describe note-writing as one of their three biggest time costs" is.

---

# Where It Misleads

**Falsifiable is not the same as tested.** This module produces hypotheses; it does not resolve
them. A run can carry a perfectly formed hypothesis to the end and still be resting on an
assumption — which is exactly what `04-problem`'s declared shortfall and Milestone Zero exist
to make visible.

**A refutation condition can be set where it will never be met.** "We are wrong if no clinician
anywhere wants this" is unfalsifiable in practice. The condition has to be one a realistic
result could satisfy.

**Hypotheses about behavior are weaker than they look.** People report intentions poorly. A
hypothesis whose test is "would you use this?" has a known bias, and `03-user` treats stated
intention as weaker evidence than observed behavior for that reason.
