# Growth Loops

---

# What It Is

Whatever compounds — tested by one question:

> **The closure test.** Does the output become the next input?

If yes, it is a loop: each turn makes the next turn cheaper or bigger. If no, it is a funnel: output scales with input, linearly,
forever.

| Loop | Funnel |
| --- | --- |
| Users produce something that attracts users | Spend produces users |
| Data improves the product, which attracts users | Content attracts users while it is published |
| Each clinic invites colleagues in the same clinic | Each conference produces leads |

> A funnel is entirely legitimate. Many good businesses grow through one. **A funnel with an arrow drawn back to the top is not** —
> that diagram implies compounding the business does not have, and it changes how the operator thinks about spend, hiring and
> valuation.

The gate records `compounding: loop | funnel | none`, and **none** is a permitted, honest answer.

---

# When It Applies

In Move 5 (Loop), after retention. Per loop: cycle time, what makes each turn bigger, where it leaks, and the evidence it works —
which before launch is usually "none, this is a hypothesis".

---

# How to Apply It Here

**Trace the output back to the input explicitly.** Name what is produced, and name how it becomes a new user. If the chain requires
spending money again, it is a funnel.

**State the cycle time.** A loop turning annually and one turning weekly are different businesses. Cycle time governs whether
compounding is relevant on the operator's timescale at all.

**Name the leak.** Every loop loses at a step — invitations not sent, content not indexed, colleagues not joining. The leak is where
the work is.

**Record the evidence, including its absence.** "No evidence; this is a hypothesis" is more useful than a diagram implying otherwise,
and it is the honest pre-launch state.

**Say plainly when it is a funnel.** Then `06-business`'s CAC arithmetic is the whole growth model, and it should be treated as such
— which changes what `07-strategy` should sequence.

---

# Where It Misleads

**A funnel is drawn as a loop.** This is the module's most consequential presentational failure: it implies compounding, which changes
spend decisions, hiring plans and how the operator understands the business.

**Market growth is presented as a loop.** `02-market/knowledge/Growth.md` names this as borrowed growth: a market's growth rate has
never acquired a user, and it does not compound for this product.

**Loops are asserted without a mechanism in the product.** Like retention mechanisms, a loop needs a requirement behind it — something
that actually produces the output and routes it to a new user.

**Cycle time is ignored.** A loop with a two-year cycle does not compound within any plan `07-strategy` is making.

**Compounding is assumed to make CAC irrelevant.** Even a working loop has a cost per turn, and the payback check applies to it exactly
as to a paid channel.
