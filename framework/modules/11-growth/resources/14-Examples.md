# Example 1 — The Payback Check Deciding Affordability

## ❌ Poor

```
Target CAC: £120 blended, in line with vertical SaaS benchmarks.
```

## ✅ Good

```
CAC ceiling  £624–£912 (margin × 6 months payback)
Implied CAC  «£x» (cost of one meeting ÷ 2 conversions)
Inside the ceiling at 2 conversions. BREACHES at 1.
That assumption decides the result, and it is untested.
```

**Why.** The check converts a debate into a comparison of two numbers, and it names the input the verdict depends on. A benchmark CAC decides
nothing because it describes another market.

# Example 3 — Switching Cost Inside Activation

## ❌ Poor

```
Onboarding: connect your records system, then record your first
consultation.
```

## ✅ Good

```
The first recording is deliberately NOT in a live consultation — a
dictated summary afterwards. Value arrives without the clinical risk
03-user identified as the binding barrier.
The records-system connection is deferred; the first note is copied
manually.
```

**Why.** The hardest step was moved out of the path to first value, and the barrier `03-user` identified as decisive is avoided rather than
argued with.

# Example 4 — Concluding "Funnel"

## ❌ Poor

```
Growth loop: satisfied users refer colleagues, driving compounding growth.
```

## ✅ Good

```
compounding: FUNNEL
Referral fails its precondition — competing practitioners do not refer.
Growth is linear in the operator's effort. Hiring is the only way to raise
throughput. Evidence any loop works: NONE.
```

**Why.** A funnel is a legitimate business. A funnel drawn as a loop implies compounding the company cannot deliver, and it changes decisions
about spend, hiring and valuation.
