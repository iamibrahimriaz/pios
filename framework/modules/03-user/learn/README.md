# Learn — User

# What This Layer Is

The human curriculum for the User module. An executing agent does not read it. Nothing
here alters a run.

---

# What the Module Does

It answers three questions: **who is served, what are they trying to get done, and what
do they do today.**

It produces five things — segments, personas, jobs to be done, the current workflow,
and the switching cost. Learners expect personas to be the centerpiece. They are the
least important output on the list.

The two that carry the framework are the **current workflow** and the **switching
cost**, and both are observational rather than inventive.

> Everything a user does today is a solution to something. The current workflow is the
> only unfaked evidence available before launch, because it is the record of what
> people already pay for in effort.

# The Three Things Worth Learning Here

**A job is not a feature.** "Wants a dashboard" is a feature request wearing a job's
clothes. The job underneath is usually about a decision someone has to make or an
account they have to give.

**The status quo is a competitor.** Whatever people do today — including a paper pad
and their own memory — works well enough that they still do it. Module 05 will
evaluate it formally; this module has to document it honestly first.

**Switching cost is a number, and it is usually underestimated.** Data migration,
retraining, workflow disruption, contractual lock-in, perceived risk. A real pain does
not move someone whose switching cost exceeds it, and that arithmetic is why good
products with obvious advantages fail to displace bad incumbents.
