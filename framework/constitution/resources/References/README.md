# References Library

---

# Overview

High-quality intelligence depends on high-quality sources.

The References library maintains a curated collection of authoritative books, research papers, official documentation, industry standards, articles, reports, and educational resources that support evidence-based product intelligence.

This library serves as the primary knowledge foundation for Product Intelligence OS.

References should strengthen understanding—not replace critical thinking.

---

# Mission

The mission of this library is to provide trustworthy, well-organized, and continuously maintained knowledge sources that improve research quality, analytical accuracy, and decision-making.

Every recommendation should be supported by reliable evidence whenever possible.

---

# Why References Matter

Reliable references help AI:

- Verify information.
- Reduce misinformation.
- Improve research quality.
- Support recommendations.
- Build credibility.
- Expand domain knowledge.

Strong references lead to stronger conclusions.

---

# Objectives

This library enables AI to:

- Discover authoritative resources.
- Validate research findings.
- Support evidence-based reasoning.
- Learn industry standards.
- Expand multidisciplinary knowledge.
- Improve documentation quality.

# Standard Structure

Each reference should include:

```
Title

Author

Publisher

Publication Date

Category

Summary

Key Topics

Why It Matters

Recommended Audience

Related References
```

Consistent metadata improves discoverability and maintenance.

---

# Selection Criteria

References should be selected based on:

- Authority
- Accuracy
- Credibility
- Relevance
- Educational value
- Long-term usefulness

Preference should be given to primary sources whenever available.

---

# Quality Guidelines

Every reference should be:

- Trustworthy.
- Current or historically significant.
- Well documented.
- Relevant.
- Properly categorized.
- Easy to locate.

Outdated or unreliable references should be reviewed regularly.

---

# Naming Convention

Use descriptive filenames.

Examples:

```
inspired-book.md

lean-startup.md

iso-9241-usability.md

google-material-design.md

react-documentation.md
```

Use recognizable names to simplify navigation.
