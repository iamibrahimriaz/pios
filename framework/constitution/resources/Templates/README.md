# Templates Library

---

# Overview

Consistency begins with structure.

The Templates library provides standardized document formats that enable AI and humans to create professional, complete, and consistent deliverables without reinventing the structure for every project.

Templates define **how information should be organized**, allowing contributors to focus on the quality of content rather than document formatting.

They serve as reusable blueprints for Product Intelligence OS.

---

# Mission

The mission of this library is to establish a common documentation standard that improves quality, accelerates work, and ensures consistency across every Product Intelligence deliverable.

Every template should reduce effort while increasing clarity.

---

# Why Templates Matter

Without standardized templates:

- Documentation becomes inconsistent.
- Important sections are omitted.
- Reviews become difficult.
- Knowledge is harder to compare.
- Collaboration becomes inefficient.

Templates provide a shared structure that improves communication and reduces unnecessary variation.

---

# Objectives

This library helps AI:

- Produce consistent documentation.
- Follow established standards.
- Reduce repetitive work.
- Improve document completeness.
- Accelerate research and planning.
- Increase collaboration efficiency.

# Standard Template Structure

Every template should include:

```
Title

Purpose

When to Use

Prerequisites

Instructions

Template Sections

Expected Outputs

Quality Checklist

Related Resources
```

Templates should guide the author without restricting critical thinking.

---

# Template Design Principles

Every template should be:

- Clear
- Modular
- Practical
- Reusable
- Easy to customize
- Easy to review
- Easy to maintain

Templates should encourage structured thinking while remaining adaptable to different contexts.

---

# Naming Convention

Use descriptive filenames.

Examples:

```
prd-template.md

market-research-template.md

competitor-analysis-template.md

product-roadmap-template.md

executive-summary-template.md
```

Names should clearly indicate the intended deliverable.

# Usage Guidelines

Templates should be used to:

- Start new projects.

Templates provide a starting point—not a finished solution.

Every template should be adapted to the specific problem, audience, and context.
